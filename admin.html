UBS Quotes Import (Excel)

UBS-Kursliste (.xlsx) mit mehreren Sheets (Indizes, Aktien, Anlagefonds, Forex, Edelmetalle, Rohstoffe, Geldmarkt, Münzen …). Spalten: Name, Price, Time (Uhrzeit hh:mm:ss → Datum des Files + Zeit, Datum dd.mm.yy → Schlusskurs an diesem Tag). Nicht zuordenbare Namen können manuell einer Security zugewiesen werden – das Matching wird gelernt und beim nächsten Import automatisch wiederverwendet.
