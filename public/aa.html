Summe

Pro Security können mehrere Zeilen erfasst werden (z.B. ein Fonds mit Anteilen in verschiedenen Regionen/Sektoren). Die Weights einer Security müssen sich auf exakt 100 % summieren – gespeichert wird nur dann; der Server prüft die Summe zusätzlich im selben Batch. Sub-Security: entweder eine Security aus der Liste wählen (gespeichert wird die SecurityID) oder einen freien Text eingeben. Country-Vorschläge stammen aus bereits erfassten Einträgen. Currency Risk: Währungscode (z.B. CHF, USD) oder „Others“; neue Zeilen übernehmen die Währung der letzten Zeile bzw. der Security.
